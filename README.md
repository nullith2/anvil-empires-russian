# Русификатор Anvil Empires

Неофициальный русский перевод **Anvil Empires Pre-Alpha** для Windows/Steam.

Автор перевода — **nullith**.

## Скачать

Готовые версии публикуются только на странице
[GitHub Releases](https://github.com/nullith2/anvil-empires-russian/releases).

Текущая версия: **v0.10.5** для проверенной Steam-сборки **24300218**,
depot manifest **590909372322551692**.

- Рекомендуемый вариант: `Anvil-Empires-Russian-v0.10.5-Setup.exe`.
- Ручная установка: ZIP-архив с PAK и инструкцией.
- Перед запуском сверяйте SHA-256 с файлом `.sha256` рядом с загрузкой.

Setup и встроенный деинсталлятор не подписаны Authenticode. Windows SmartScreen
может показать предупреждение. Для проверенного файла после сверки SHA-256
можно выбрать «Подробнее» → «Выполнить в любом случае».

## Совместимость

Точное совпадение Steam build, depot manifest и EXE с проверенной сборкой
устанавливается без предупреждения. При расхождении Setup сообщает, что
совместимость не подтверждена, и продолжает только после отдельного явного
согласия пользователя на риск.

Setup по-прежнему блокирует установку, если Steam обновляет игру, выбрана не та
игра или папка, язык игры не `English`, клиент запущен либо обнаружен конфликт
PAK. Русификатор не заменяет штатный `Anvil-Windows.pak`.

## Состав v0.10.5

- 2 920 LocRes-записей: 2 542 cooked и 378 native identity;
- перевод интерфейса, предметов, сооружений, производства, заданий и системных
  сообщений;
- кириллическая замена шрифта;
- полный offline-прогон: 116 тестов;
- выборочный runtime smoke пройден на целевой сборке.

Серверные сообщения, текст внутри изображений, некоторые raw-строки голосового
чата и редкие игровые ветви могут оставаться английскими.
