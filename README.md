# Русификатор Anvil Empires

Неофициальный русский перевод **Anvil Empires Pre-Alpha** для Windows/Steam.

Автор перевода — **nullith**.

## Скачать

Готовые версии публикуются только на странице
[GitHub Releases](https://github.com/nullith2/anvil-empires-russian/releases).

Текущая версия: **v1.0.1** для версии игры **90114**
(Steam build **24619810**).

- Скачать: `Anvil-Empires-Russian-v1.0.1-steam-build-24619810.zip`.
- SHA-256 архива будет указан в описании соответствующего релиза.

Архив не содержит EXE и установочных скриптов. В нём находятся PAK, инструкции,
правовые уведомления и машинный манифест `nfg-package.json`.

## Совместимость

Пакет подготовлен и проверен для указанной версии игры. При другом Steam build
совместимость не подтверждена. После обновления игры безопаснее удалить PAK и
дождаться совместимого выпуска. Русификатор не заменяет штатный
`Anvil-Windows.pak`.

## Установка

1. Полностью закройте Anvil Empires.
2. Распакуйте ZIP.
3. Скопируйте `Anvil-Russian-Full_P.pak` в
   `Anvil Playtest\Anvil\Content\Paks`.
4. Убедитесь, что в этой папке активен только один сторонний русификатор с
   расширением `.pak`.
5. Запустите игру через Steam с выбранным языком `English`.

Для удаления закройте игру и удалите только `Anvil-Russian-Full_P.pak`.

## Машинный манифест

В корне ZIP рядом с PAK находится `nfg-package.json` схемы `nfg-package/1`.
Он описывает установку PAK в
`steam-game/Anvil/Content/Paks/Anvil-Russian-Full_P.pak` и содержит точные
версию выпуска, Steam App/build ID, размер и SHA-256 файла.
