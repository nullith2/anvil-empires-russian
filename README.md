# Русификатор Anvil Empires

Неофициальный русский перевод **Anvil Empires Pre-Alpha** для Windows/Steam.

Автор перевода — **nullith**.

## Скачать

Готовые версии публикуются только на странице
[GitHub Releases](https://github.com/nullith2/anvil-empires-russian/releases).

Текущая версия: **v0.10.6** для версии игры **89425**
(Steam build **24300218**).

- Рекомендуемый вариант: `Anvil-Empires-Russian-v0.10.6-Setup.exe`.
- Ручная установка: `Anvil-Empires-Russian-v0.10.6-steam-build-24300218.zip`.
- Перед запуском сверяйте SHA-256 с таблицей в описании соответствующего релиза.

Setup и встроенный деинсталлятор не подписаны Authenticode. Windows SmartScreen
может показать предупреждение. Для проверенного файла после сверки SHA-256
можно выбрать «Подробнее» → «Выполнить в любом случае».

## Совместимость

Если установленная версия игры отличается от поддерживаемой, установщик
предупреждает о возможной несовместимости. Продолжить установку можно только
после явного подтверждения пользователя.

Setup блокирует установку, если Steam обновляет игру, выбрана не та
игра или папка, язык игры не `English`, клиент запущен либо обнаружен конфликт
PAK. Русификатор не заменяет штатный `Anvil-Windows.pak`.

## Состав v0.10.6

- 2 920 записей локализации;
- перевод интерфейса, предметов, сооружений, производства, заданий и системных
  сообщений;
- кириллическая замена шрифта.

В этой версии сокращены строка срока содержания городской крепости и подписи
вкладок Центрального рынка, чтобы текст не выходил за границы интерфейса.

Серверные сообщения, текст внутри изображений, некоторые raw-строки голосового
чата и редкие игровые ветви могут оставаться английскими.

## Обратная связь

Об ошибке перевода можно сообщить через
[GitHub Issues](https://github.com/nullith2/anvil-empires-russian/issues).
Приложите скриншот, укажите отображаемую в игре версию и кратко опишите
действие, после которого появился текст. Steam build ID можно добавить, если
он известен.

## Проверка Setup

Исходники установщика находятся в каталоге
[`installer-source`](installer-source). Приложенный сценарий собирает Setup
непосредственно из официального ZIP и принимает результат только при точном
совпадении размера и SHA-256 с опубликованным EXE. Обычному пользователю для
установки это не требуется.
