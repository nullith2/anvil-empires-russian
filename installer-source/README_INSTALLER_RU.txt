ANVIL EMPIRES — РУСИФИКАТОР
============================

Этот файл относится к установке через Windows Setup.

Автор: nullith
Репозиторий: https://github.com/nullith2/anvil-empires-russian
Поддержка: https://github.com/nullith2/anvil-empires-russian/issues
Условия использования: INFO\LICENSE_RU.txt в официальном выпуске

Setup и встроенный деинсталлятор не подписаны Authenticode. Windows SmartScreen
может показать предупреждение. Запускайте Setup только из официального релиза
проекта после сверки SHA-256 с опубликованной рядом контрольной суммой.

УСТАНОВКА И ОБНОВЛЕНИЕ
----------------------

1. Полностью закройте Anvil Empires.
2. Запустите Setup. Он сам найдёт библиотеки Steam и проверит App ID, build,
   depot manifest и исполняемый файл игры.
3. Если игра не найдена автоматически, выберите её корневую папку внутри
   steamapps\common.
4. Для обновления запустите Setup новой версии: принадлежащий
   установщику PAK будет заменён транзакционно.

При точном совпадении build, depot manifest и EXE с проверенной сборкой Setup
сразу разрешает установку. При расхождении он показывает заметное предупреждение
о неподтверждённой совместимости и продолжает только после вашего явного
согласия установить перевод на свой страх и риск. Такое продолжение не означает,
что сборка совместима.

Язык игры в Steam должен быть English. Установщик изменяет только
Anvil-Russian-Full_P.pak и не трогает штатный Anvil-Windows.pak либо файлы
.disabled.

Setup жёстко блокирует установку, если Steam ещё обновляет игру, выбраны не та
игра или папка, App ID неверен, язык не English, игра запущена либо обнаружен
конфликт PAK.

УДАЛЕНИЕ
--------

1. Полностью закройте игру.
2. Откройте «Параметры Windows» → «Приложения» → «Установленные приложения».
3. Удалите «Русификатор Anvil Empires».

PAK удаляется только при совпадении сохранённых пути и SHA-256. Если файл был
изменён после установки, удаление остановится и сохранит как PAK, так и запись
деинсталлятора. Уберите изменённый PAK вручную либо восстановите исходный файл,
после чего повторите удаление.

ДИАГНОСТИКА
-----------

- Setup предупреждает о другой сборке: безопаснее дождаться совместимого
  выпуска; продолжение доступно только после явного принятия риска и не
  подтверждает совместимость.
- Найден другой активный Anvil-Russian*.pak: вынесите его из папки Paks или
  переименуйте так, чтобы имя не заканчивалось на .pak.
- Нет доступа к папке Paks: дайте своей учётной записи доступ к библиотеке
  Steam либо перенесите игру в доступную библиотеку.
- Интерфейс остался английским: проверьте язык English и отсутствие второго
  активного локализационного PAK.

Точные сведения о совместимости, составе, контрольной сумме PAK и известных
ограничениях находятся в README_RU.txt и RELEASE_NOTES_RU.txt рядом с этим
файлом. ZIP-релиз остаётся вариантом для ручной установки.
