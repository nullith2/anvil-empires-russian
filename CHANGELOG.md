# История выпусков

## v1.0.0 — версия игры 89454 (Steam build 24378492)

- 2 926 записей локализации.
- Добавлены переводы предупреждения об отсутствии городов, заголовка очереди
  на сервер и кнопки выхода из очереди.
- Переведены оба уведомления о времени до обрушения Подземья.
- Переведено расстояние до ближайшего города; отображение подтверждено в игре.
- В корень ZIP добавлен `nfg-package.json` схемы `nfg-package/1` с точными
  назначением, размером и SHA-256 PAK.
- Выпуск распространяется как ZIP без EXE и установочных скриптов.

## v0.10.6 — версия игры 89425 (Steam build 24300218)

- 2 920 записей локализации.
- Сокращена строка срока содержания городской крепости.
- Сокращены подписи вкладок Центрального рынка, чтобы устранить наложение
  текста.
- Setup теперь побайтово воспроизводится из публичного ZIP и опубликованных
  исходников установщика.
- Раскрытый каталог релиза и содержимое ZIP используют одну структуру с
  отдельной папкой `INFO`.

## v0.10.5 — версия игры 89425 (Steam build 24300218)

- 2 920 записей локализации.
- Обновлена совместимость после изменения клиента игры.
- Добавлены и проверены новые runtime-строки, включая окна выбора фракции,
  выхода и роспуска аватара.
- В Setup добавлено предупреждение для неподтверждённых сборок с отдельным
  осознанным продолжением на риск пользователя.
- Сохранены жёсткие блокировки обновления Steam в процессе, неправильной игры,
  языка не English, запущенного клиента и конфликтующих PAK.
- В мастер Setup добавлена страница с автором и официальными ссылками проекта.
- Добавлены пользовательские условия `LICENSE_RU.txt`.
- Полный offline-набор: 116 успешных тестов.
- Выборочный runtime smoke на целевом PAK пройден.

## Известные ограничения

Серверные, raw- и raster-строки, а также редкие игровые ветви могут оставаться
английскими.
